# Contributing to Awesome ThinkSmart

Thanks for helping make this list more useful! A few ground rules:

## What to add

- Resources specifically about the Lenovo ThinkSmart View (CD-18781Y): ROMs, guides, tools, source code, projects, research, community threads.
- Only things that work (or clearly-labeled work-in-progress with real substance). Link to the original source, not a repost or SEO copy.
- For downloads and unofficial builds, prefer links from the maintainer's own repo or post; note when a link is a community mirror.

## How to add

- One item per line, in the most specific section. Format:

  ```markdown
  - [Name](https://link) — Short description ending with a period.
  ```

- Keep descriptions one sentence where possible; put longer context in the linked resource, not here.
- If a resource is unofficial, abandoned, or region/hardware-specific, say so in the description.
- Add the item to the English `README.md`; the Chinese `README.zh-CN.md` will follow (or update both, matching style).
- Check your links before opening a PR.

## What not to add

- Affiliate links, referral trackers, or your own store listings.
- "Why this device is great" blog posts that add nothing beyond marketing.
- Anything pirated or that redistributes proprietary blobs outside their upstream license.

## Code of conduct

Be kind. Credit original authors. This is a niche, volunteer-driven corner of the internet — the people who built these ROMs and guides did it for free.
